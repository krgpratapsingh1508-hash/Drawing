# 🎨 Bacho ki Drawing Book

Streamlit app jo har baar naye coloring pages (drawing book) banata hai.
Bacha jitni baar link kholega ya "Naya Drawing Book Do" dabayega, utni baar nayi drawings milengi.

## Files
- `app.py` – Streamlit app
- `drawing.py` – drawing pages banane ka code (sirf Pillow)
- `requirements.txt` – libraries

## Local me chalana
```
pip install -r requirements.txt
streamlit run app.py
```

## GitHub + Streamlit par online karna
1. GitHub par naya repository banao aur ye 4 files upload karo.
2. https://share.streamlit.io par GitHub se login karo.
3. **Create app** → apni repository chuno → Main file path: `app.py` → **Deploy**.
4. Kuch der me aapko public link mil jayega, wahi bacho ko bhejo.
